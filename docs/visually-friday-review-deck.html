Canvas Assistant
In the builder
A conversational data analyst embedded in the canvas.
  • Plain-English question → SQL on your live database
  • Generates chart widgets and drops them onto a page
  • Schema-RAG grounding + deterministic time filters
  • Self-healing retries · read-only, whitelisted tables only
Report Copilot
In the report
The intelligence page's embedded copilot.
  • Same NL → SQL + instant charts, scoped to the report's tables
  • Smart response modes: answer · explain · look-up · build
  • VizSwitcher — flip any chart Bar / Line / Pie / Table
  • One-click export to Excel
Every copilot is read-only — whitelisted tables, no DDL/DML, no system catalogs.
